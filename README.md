# 📊 Product Dashboard

A responsive and interactive Product Management Dashboard built with **React.js and Tailwind CSS**. Manage products efficiently with CRUD operations, real-time search, status filtering, and dynamic pagination — all through a clean and user-friendly interface.

## 🚀 Features

- **Product Management (CRUD):** Add, edit, and delete products.
- **Search Functionality:** Search products by name or price.
- **Status Filtering:** Filter products by Active and Inactive status.
- **Dynamic Statistics:** View total, active, and inactive product counts.
- **Pagination:** Display 5 products per page with Previous and Next navigation.
- **Local Storage:** Persist product data across browser refreshes.
- **Responsive Design:** Optimized layouts for mobile, tablet, and desktop.
- **Empty State Handling:** Displays a message when no matching products are found.
- **Interactive UI:** Custom dropdowns, modal forms, and intuitive action icons.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Product-Dashboard
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit the local URL provided by Vite, usually:

```text
http://localhost:5173
```
